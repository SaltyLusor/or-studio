Allgemeine Hinweise zur Datenverarbeitung

Personenbezogene Daten sind alle Informationen, durch die eine Person unmittelbar oder mittelbar identifiziert werden kann. Dazu gehören beispielsweise Namen, E-Mail-Adressen und IP-Adressen.

Die Verarbeitung personenbezogener Daten erfolgt nur, wenn hierfür eine rechtliche Grundlage besteht oder die Verarbeitung für den technischen Betrieb dieser Website erforderlich ist.

Soweit in dieser Datenschutzerklärung keine besondere Speicherdauer genannt wird, werden personenbezogene Daten gelöscht, sobald der Zweck ihrer Verarbeitung entfällt und keine gesetzlichen Aufbewahrungspflichten entgegenstehen.

Speicherung des Farbschemas

Auf OR Studio kann zwischen einem hellen und einem dunklen Farbschema gewählt werden.

Die Auswahl wird unter dem Schlüssel theme im Local Storage des verwendeten Browsers gespeichert. Dadurch kann das gewählte Farbschema beim nächsten Seitenaufruf automatisch wiederhergestellt werden.

Dabei werden keine Namen, E-Mail-Adressen, Nachrichten oder sonstigen Kontaktdaten gespeichert. Die gespeicherte Auswahl wird nicht an OR Studio übermittelt.

Die Speicherung kann über die Einstellungen des Browsers oder durch das Löschen der Website-Daten entfernt werden.

Font Awesome über cdnjs

Für die Darstellung von Symbolen und Icons wird Font Awesome über das Content Delivery Network cdnjs geladen.

cdnjs wird über die Infrastruktur von Cloudflare bereitgestellt. Beim Laden der Font-Awesome-Dateien wird eine Verbindung zu Servern von Cloudflare hergestellt.

Dabei können insbesondere die IP-Adresse, der Zeitpunkt des Zugriffs, Browserdaten sowie Informationen über die aufgerufene Datei verarbeitet werden.

Die Einbindung erfolgt, um Icons einheitlich und technisch zuverlässig darzustellen. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt in einer ansprechenden und funktionsfähigen Gestaltung der Website.

Eine Datenübertragung in die USA oder andere Drittländer kann nicht ausgeschlossen werden.

Eingebettete TikTok-Inhalte

Falls du bei TikTok angemeldet bist, kann TikTok den Besuch dieser Website unter Umständen deinem TikTok-Konto zuordnen.

Externe Links und Social Media

Diese Website enthält Links zu externen Plattformen, insbesondere Instagram, TikTok, GitHub und Twitch.

Beim bloßen Anzeigen eines normalen Links wird grundsätzlich noch keine Verbindung zur jeweiligen Plattform hergestellt. Erst wenn du den Link anklickst, wird die externe Website geöffnet.

Ab diesem Zeitpunkt gelten die Datenschutzbestimmungen des jeweiligen Anbieters. OR Studio hat keinen Einfluss darauf, welche Daten die externe Plattform verarbeitet oder wie lange diese gespeichert werden.

Kontaktformular

Auf der Kontaktseite befindet sich derzeit ein Kontaktformular mit Feldern für Name, E-Mail-Adresse und Nachricht.

Das Formular ist aktuell eine technische Demonstration. Beim Absenden wird die Standardübertragung im Browser durch JavaScript verhindert.

Die eingegebenen Daten werden derzeit weder an einen Server noch an einen externen Formulardienst übermittelt. Es findet keine dauerhafte Speicherung durch OR Studio statt.

Nach dem Absenden wird lediglich eine lokale Hinweismeldung angezeigt. Anschließend können die Formularfelder im Browser zurückgesetzt werden.

Sobald zukünftig ein tatsächlicher Versand über einen Server, einen E-Mail-Dienst oder einen externen Formularanbieter eingerichtet wird, muss dieser Abschnitt entsprechend aktualisiert werden.

Verschlüsselte Verbindung

Die Website wird über eine verschlüsselte HTTPS-Verbindung bereitgestellt. Dadurch werden übertragene Daten während der Verbindung zwischen Browser und Server vor einem einfachen Mitlesen durch Dritte geschützt.

Eine vollständige Sicherheit bei der Datenübertragung über das Internet kann jedoch nicht garantiert werden.
